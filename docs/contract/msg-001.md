# MSG-001 capability rules

The following source rules are retained from the contract at `ca2596bae4c081a2df169d327b23c0030428b918`. Current acceptance and company-policy classes are defined by CONTRACT.md.

**Semantics (MSG-001):** a template version carries up to five attachments of up to 1 MiB each; an edit keeps the previous version's files unless it replaces them, and a version's files never change.

**Composition doors (MSG-001):** document reminders, PORTAL-004 organizer invitations, portal messages (PORTAL-003) and bulk messages (MSG-002) compose from these templates today with the same preview, refusal, files and stored rendered text. A portal message is rendered for one authorized contact of the job (the chosen one, else the only or primary one), appears on the client's link and carries the version's files for download there. It holds at most 2,000 characters once rendered, and `{{portal_link}}` renders as "this secure page" because the client is already on their link and no new link is made. A bulk message cannot be filled in per recipient: a recipient whose rendering leaves a placeholder unresolved is excluded at preview with the field named (or held, not sent, if it changes before dispatch). Document reminders and PORTAL-004 organizer invitations compose from these templates. Inbox replies (MAIL-001), portal messages (PORTAL-003), reminder-sequence steps (FOLLOWUP-001), signature and invoice notices (SIGN-001, BILL-004), text messages (SMS-001) and bulk messages (MSG-002) each compose from these templates, with the same preview, refusal, attachments and stored rendered text, before they ship.
