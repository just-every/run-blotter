# DOC-003 capability rules


**DOC-003 — Client approval of deliverables.** Staff send a deliverable such as a draft return copy, financial statements or a management report for client approval.

**DOC-003 — Client approval of deliverables.** Status: **done**. Send version 1 of a set of financial statements. The client requests a change with a comment. Upload version 2 and have the client approve it. Inspect the approval bound to version 2's hash, the retained comment on version 1 and the resulting status change. Approving version 1 after version 2 exists is refused.
