# CAPACITY-003 capability rules

The following source rules are retained from the contract at `ca2596bae4c081a2df169d327b23c0030428b918`. Current acceptance and company-policy classes are defined by CONTRACT.md.

**Semantics (CAPACITY-003):** a manager (a reviewer or the principal, as in CAPACITY-002; a preparer sees only their own capacity under CAPACITY-001) forecasts 1 to 53 Monday-to-Sunday weeks (UTC dates) from a Monday.

**Pipeline (CRM-005):** each open prospect’s requested service contributes its own visible unweighted assumption that the prospect wins, with current stage, source, owner and whole-prospect annual fee in its stored currency. An exact case-insensitive service/work-type name match is the default; the manager may choose another work type or leave the service unestimated. Its first assumed work target defaults to the forecast start or is selected per service; demand repeats at the selected template’s monthly/quarterly/annual cadence through the window, or occurs once without a template. Each engagement uses the same no-actuals estimate chain as recurring work (work-type budget, else template task estimates), with a 50%–150% range rounded to the minute. Missing matches or budgets contribute zero explicitly labeled unestimated, with a named low-confidence reason. Pipeline demand counts in weekly and skill totals in baseline and scenarios; service percentage changes scale it too. Fees never become hours. Won and lost prospects are excluded. These assumptions create no assignments, signed scope or promised deadlines. Saved scenarios retain the selected work type and first target and recompute from current records. CAPACITY-003 is done for every capability that exists today.
