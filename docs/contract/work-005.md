# WORK-005 capability rules


**WORK-005 — Firm work queues.** Staff see a due-date-ordered work queue with client, period, preparer, reviewer, status and outstanding checklist/document counts.

**WORK-005 — Firm work queues.** Status: **done**. Create two jobs for different preparers, open the work queue as each role and inspect dates, assignees, status and outstanding counts. Directly requesting another preparer's hidden job is refused.
