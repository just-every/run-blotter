# AGENT-001 capability rules


**AGENT-001 — Agents prepare people approve.** A separately keyed agent reads role-scoped context and prepares roll-forward, reminder or billing-export proposals for its named human.

Only that human may approve or decline.

Agent narrative never approves work or a bill.

**AGENT-001 — Agents prepare people approve.** Status: **done**. Create a key, prepare all three proposal kinds, attempt approval with the key, approve as its human and decline another with a reason. Inspect decision/result history, refusal of a second decision and immediate key revocation.
