# WORK-001 capability rules


**WORK-001 — Reusable engagement templates.** A principal or reviewer creates reusable monthly, quarterly or annual templates containing a checklist, document request list and fixed fee.

**WORK-001 — Reusable engagement templates.** Status: **done**. Through the app or authenticated HTTP doors, create a recurring template, start a client job and inspect copied checklist, requests, recurrence, fee, preparer and reviewer. A preparer cannot create templates.
